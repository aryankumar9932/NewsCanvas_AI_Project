# Limitations and responsible AI

- Demo summaries select source sentences; demo artwork is a labeled SVG, not model inference.
- Keyword/entity/sentiment analysis uses heuristics and can be wrong.
- Optional model performance depends on the model, hardware, endpoint, and provider terms.
- Images can misrepresent events. Label them illustrations, not documentary photographs.
- URL retrieval is conservative but requires further production hardening and network-level egress controls.
- There is no authentication or per-user access control; keep local until added.
- News truth and source credibility are not independently verified.
